# 第二篇大纲

记录正文现在怎么走，不记论证，不抄代码。每节只写三样：回应什么问题，造了什么、认出了什么，第一次出现的名字。改叙事的 PR 先改这里，再改正文；只改措辞的 PR 不用动它。

标题：箭头指向何方：CPS 与否定翻译

## 0. 开头

- 接第一篇的两根线头：构造性语言怎么支持经典推理；程序内部的相对 $⊥$。本篇回答第一根。

## 1. 求值顺序与 ANF

- 问题：嵌套表达式看不出求值顺序。
- 造：用 `let*` 给中间结果起名（ANF）；`let` 脱糖为 λ 调用。
- 认：等待结果的 λ 是**延续**；`(let ([y (f x)]) (g y))` 就是 `((∘ g f) x)`；`let` 嵌在 `b` 还是 `e` 里是**结合律**；换名的 `let` 是**单位律**。
- 名字：ANF、redex、延续、`∘`、`id = (∘)`、结合律、单位律。
- 注意框：后一步用到多个名字的情形不在本文范围。

## 2. 延续与 CPS

- 问题：把延续取出来作为参数。
- 造：`fact/k`、`fib/k`；累积器版 `fact/k` 不增长闭包链。
- 认：所有调用成了尾调用；栈的增长搬到了堆上的闭包链。
- 名字：$¬$、$⊥$ 的类型读法，闭包链。

### 2.1 终结延续

- 问题：启动 CPS 函数交进去什么。
- 造：`exit` 不合适；用 `raise` 和 handler 造 `a->⊥`、`⊥->a`。
- 名字：终结延续、`ans`、`a->⊥`、`⊥->a`。

### 2.2 一等控制

- 问题：延续是一等值，不用 `call/cc` 能否写短路。
- 造：CPS 版 `mul`，遇零改调 `a->⊥`。
- 认：控制流就是选择调用哪条延续。
- 留下的抱怨：每个延续都得手写。

## 3. 否定的层次

- 问题：可变参数函数分不开延续与操作数。
- 造：柯里化把延续独立出来，得到 `neg`（延续在前）与 `cps`（延续在后）；`flip` 交换参数。
- 认：两者的类型是逆否律与 DNI 的推广；`flip` 是自己的逆，两行 `case→` 读法；`cps = (∘ flip neg)`；`(neg f)` 把 `f` 复合到延续前面，接两次就是闭包链。
- 名字：`neg`、`cps`、`flip`、`case→`、逆否律、DNI、`mul3`。
- 练习：只用 `neg`、`cps` 写出 `flip`。

### 3.1 三种箭头

- 问题：三种命题形状反复出现。
- 造：别名 `→𝒞`、`→𝒦`、`→𝒰`；`∘𝒰`（`∘` 反过来）；`∘𝒦`（经 `flip` 搬到 𝒰 复合再搬回）。
- 认：单位元是零元复合：`neg:id = (∘𝒰)`、`cps:id = (∘𝒦)`；展开 `∘𝒦` 两支，得到手写 `fib/k` 时的包法；三种复合都满足单位律、结合律。
- 名字：世界 𝒞、𝒦、𝒰，`∘𝒰`、`∘𝒦`、`neg:id`、`cps:id`。
- 练习：一支箭头的 `∘𝒦`。
- 注意框：纯性与「收到参数只造出等待延续的函数」的前提。

## 4. 经典与构造

- 问题：能否把 𝒰、𝒦 的箭头转回 𝒞。
- 认：两个方向的类型是 DNE 与逆否律之逆，经典定理。
- 造：`uncps = (∘ call/cc cps:f)`；验证两个方向都是恒等，$𝒦 ≅ 𝒞$；三世界交换图；`unneg`。
- 名字：DNE、`uncps`、`unneg`、交换图表。
- 注意框：同构的三个前提。

### 4.1 两个 call/cc

- 问题：同构说 𝒰、𝒦 拥有经典逻辑的力量，所以也应各有 `call/cc`。
- 造：`¬𝒦`、`¬𝒰`；`cps:call/cc`、`neg:call/cc`，把延续参数提升后交给 `proc`。
- 认：只用 lambda，经典力量从延续编码中长出来。
- 练习：验证两者的类型是 Clavius 律。

### 4.2 落回 𝒟

- 问题：回 𝒞 要 `call/cc`；搭建 𝒰、𝒦 却不用。能否不消除 $¬¬$，直接落回纯宿主？
- 造：把宿主拆成 𝒞 与 𝒟，`inj`；发现 𝒰 箭头读回宿主时两端对调；`←`、`⨾`，`∘𝒰 = ⨾`；`neg` 的第二种读法 $(¬q → ¬p) → (¬¬p → ¬¬q)$。
- 名字：𝒟、`→𝒟`、`inj`、`←`、`⨾`。

### 4.3 否定翻译

- 造：四世界表与四世界图；`neg² = (∘ neg neg)`，签名 𝒞 → 𝒟。
- 认：`neg²` 只翻译类型，不翻译程序；程序要落在 𝒟 里，得每步写成 𝒦 箭头、用 `cps:call/cc` 与 `∘𝒦`。命名**否定翻译**。
- 名字：`neg²`、否定翻译。
- 练习：从 𝒦 经 𝒰 到 𝒟 的路径。
- 注意框：Kuroda 与 Kolmogorov 的变体。
- 收尾：一等控制有了，写法还是 CPS，中间结果没有名字。

## 5. 再次隐藏延续

- 问题：用 `let` 把 CPS 的延续藏回去；`(1 + 2) × 3` 里 `cps:mul3` 用不上 `kk3`。
- 造：前面接一支 $¬¬\text{Nat} →_𝒦 \text{Nat}$ 的箭头，认作 `(neg² id)`，记 `neg²:id`；展开得到手写 CPS 的样子。
- 认：`let` 与 `anf:let` 并排，分别是 `∘` 与 `∘𝒦` 的另一种写法；拿掉 `neg²:id` 的等式；两条运算律的绑定形状。
- 造：宏 `anf:let*-values`、`anf:begin`、`anf:let*`、`anf:if`、`anf:let/cc`；解释器 `anf:eval`。
- 名字：`kk3`、`cps:mul3`、`neg²:id`、`anf:` 系列、`anf:eval`。
- 练习：拿掉 `neg²:id` 的前提；推出四条运算律等式。

## 6. 嵌入语言

- 造：用 `cps` 提升宿主函数；嵌入语言版 `mul`（`anf:let/cc` 逃逸）；阴阳谜题与 `cps:label`。

### 6.1 计算的位置

- 认：每个绑定处有一个具体的延续；相邻两处只差 `(neg f)`；构造从 `a->⊥` 向内，运行时值向外。
- 名字：计算位置。

## 7. 结论

- 回看：同样的 `let*`，背后的复合从 `∘` 换成 `∘𝒦`。

### 7.1 未解的线索

- 𝒟 能编码、能复合，交不出终结延续；`a->⊥` 是借来的；$⊥$ 到底是什么。
