# 正文代码块的写法

定义块用 `racket` 围栏，照文件写定义和类型标注，不带提示符。求值时有打印的定义可以写进交互块。

交互块也用 `racket` 围栏，首个非空行以 `> ` 开始。每个输入的第一行带 `> `；多行输入的后续行在原来的缩进上再加两个空格。输入之后原样写 REPL 的打印、返回值和错误，再用 `> ` 开始下一项：

```racket
> (displayln "hello")
hello
> (+ 1 2)
3
> (let ([x 3])
    (+ x 4))
7
```

返回值按读入后的数据比较，换行与缩进可以为可读性调整。

正文展示编译后程序的运行结果、但没有给出对应输入式时，用不带语言标记的输出块。

无限输出以 `...` 标记截断位置，核对器检查已有的前缀。推导等式保留 `racket` 围栏；顶层带 `=` 的等式块自动跳过，其他示意块在 `blocks.rktd` 中写明跳过原因。`tools/run-blocks.rkt` 核对交互结果，`tools/cmp-forms.rkt` 只从定义块收集定义。
